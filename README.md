## About

**OSINT-Python-Modular-fTech** is a modular Python project designed to explore and organize Open Source Intelligence (OSINT) workflows.

The project aims to provide a structured environment for developing independent OSINT modules, collecting publicly available information, and performing basic data analysis.

Built with Python, the project focuses on modularity, readability, and extensibility.

## Project Goals

- Build a modular and maintainable OSINT toolkit.
- Organize different intelligence-gathering techniques into independent modules.
- Practice Python automation and data processing.
- Understand digital footprints and publicly available information.
- Develop practical skills in cybersecurity and information analysis.

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/OSINT-Python-Modular-fTech.git
```

### 2. Navigate into the project

```bash
cd OSINT-Python-Modular-fTech
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Linux / Kali Linux**
```bash
source venv/bin/activate
```

**Windows**
```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```
